# Art credits

Type Splash does not ship third-party sprite packs yet. The pool, swimmers, letter tile, and keyboard are Phaser Graphics in `src/game/`. Sounds are synthesized in `src/game/audio.ts`.

When a pack is added, drop the raw files in `assets/sprites-src/` (then `pnpm atlas`) and add a row here.

## Approved sources

| Source | URL | License notes |
| --- | --- | --- |
| Kenney | https://kenney.nl/assets | CC0 — public domain, commercial use OK |
| itch.io game assets | https://itch.io/game-assets | Check each pack page; prefer CC0 / CC-BY / paid commercial licenses |
| CraftPix | https://craftpix.net/ | Free and paid 2D packs; commercial use allowed (read the pack's license) |

Do not add or buy art unless someone asks.
